# Loop 10 — the other half of the job: not retiring what is still true

Every loop before this measured recall — given a decision and the message that replaces it,
is the first one retired. `kept_b` checks that the replacement survives, and loops 8 and 9
check that an unrelated *commit* retires nothing. Nothing measured what a later message
does when it is about something else and happens to share words with an earlier one, which
is what most of a real conversation looks like.

The gap was found by running the engine on a real store rather than a fixture: six of this
project's own transcripts, 395 records, and of four sampled conversational retirements three
looked wrong. One of them retired a note about `gzip`/`zstd` because a later message
described *running a test* on gzip and zstd.

## Three sets

Each is 15 pairs generated by `claude-haiku-4-5` from its own prompt, one store per pair, no
model in the measurement. `kept_a` is the gate: the first message must still be served.

| set | what it is | before | after |
|---|---|---|---|
| `pairs.json` | two messages sharing two or more content words, both still true | 14/15 | **15/15** |
| `pairs2.json` | the same, generated again with the first set's topics excluded | 15/15 | **15/15** |
| `pairs3.json` | the same, with the second message required to use *migration, replacement, cambios, swap, switch, rollback* as an ordinary noun | 3/15 | **12/15** |

`kept_b` is 15/15 everywhere, before and after.

The second set is the honest hold-out and it says the fix costs nothing; it does **not**
replicate the gain, because it happens not to contain the failure mode — the pre-fix binary
also scores 15/15 on it. The third set was generated to contain the failure mode on purpose,
and it is where the size of the problem shows: **three of fifteen** true decisions survived a
following sentence that merely used one of those words as a noun.

Of the three that still fail on set 3, two are arguably correct retirements that the
generator labelled as not-replacements — "the authentication service swap to OAuth2 took six
weeks" and "the frontend framework switch to Next.js caused some confusion" do read like the
decision changing — and one fires on `instead of`, which is a genuine change marker in a
sentence that is not one. Those are labelling limits of a model-written set and are reported
rather than curated away.

## What the one failure was, and what it cost

`we use PostgreSQL for user data` was retired by `user data migrations run in CI`. The two
share `user` and `data`, which is enough overlap for the supersession rule, and the second
message counted as *announcing a change* — because the change-marker pattern was `\bmigrat`,
which matches the noun `migrations` as readily as the verb `migrating`. The Spanish `\bcambi`
did the same for `los cambios fueron…`, which is how a real record about a Codex bug fix was
retired by an unrelated message.

Four prefixes now require a verb form: `migrat`, `replac`, `cambi`/`migra` and
`reemplaz`/`sustitu`, with `cambio a|de|al` kept because it is how the change is actually
announced in Spanish. `swap` and `switch` want a direction within a short distance — `swap
sharp out`, `switch to Next.js` — rather than the bare noun, which is what `Redis cache swap
freed 2GB` was. `a_noun_is_not_an_announced_change` pins both directions, and the loop-2
development case `swap sharp out, thumbnails go through libvips now` is what forced the
bounded gap rather than a fixed preposition.

**The cost is zero.** Every recall figure in loops 8 and 9 is unchanged, both orders and both
arms: `talk` retired 17/30 and 17/30 adjacent, 6/30 and 5/30 in blocks; `both` 30/30 and
29/30 adjacent, 29/30 and 29/30 in blocks; delivered 11/30 and 8/30 for `talk`, 19/30 and
21/30 for `both` adjacent, 17/30 and 25/30 in blocks. On the real store, retirements at ingest
fell from 13 to 11 and the two that remain are records of pasted tool output rather than
decisions.

## Reproduce

```sh
for p in pairs pairs2 pairs3; do
  python3 crates/muninn-bench/experiment/loop10/eval_precision.py \
      --muninn target/release/muninn \
      --pairs crates/muninn-bench/experiment/loop10/$p.json --out /tmp/$p.json
done
```
