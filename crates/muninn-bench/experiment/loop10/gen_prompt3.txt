Write pairs of short messages a software developer might type to a coding assistant. In each pair the two messages are about DIFFERENT things that share TWO OR MORE ordinary content words, and the second message must NOT replace, revise or contradict the first: both stay true at the same time.

Extra requirement: the SECOND message of every pair must contain one of these words used as an ordinary noun, never as an announcement of a change — migration, migrations, replacement, replacements, cambios, sustitución, reemplazo, swap, switch (the noun), rollback (the noun).

Example of the shape (do not reuse it):
  a: "the orders table is partitioned by month"
  b: "the orders table migration takes about four minutes"      (share: orders, table)

Make 15 pairs: five terse, five chatty, five Spanish. Use realistic technology names.

Output JSON only: a list of 15 objects {"key","a","b","shared"} where key is a short slug prefixed "p12-" and suffixed "#terse", "#chatty" or "#Spanish".
