Logo files. Source: a brand sheet generated with Codex on 2026-09-17 (primary emblem, horizontal
lockup, companion mark). Each file was cut from that sheet; the backgrounds and drop shadows were
removed, and the light-ink versions were made by inverting the ink while keeping the amber eye and
its pupil.

- `muninn-light.svg`, `muninn-dark.svg` the horizontal lockup as vectors, traced from the PNGs
  below: the ring redrawn as exact arcs with its gaps where the PNG has them, the raven and the
  wordmark traced with their edges smoothed, the eye redrawn as an iris and a pupil. The README
  animations draw the logo from these paths.
- `muninn-light.png` horizontal lockup, dark ink on a transparent background, for light backgrounds
- `muninn-dark.png` the same lockup in light ink, for dark backgrounds
- `muninn-symbol.png` the companion mark on dark, 512 × 512 (avatar, favicon)
- `muninn-social.png` 1280 × 640, GitHub social preview: primary emblem, wordmark and tagline
