Muninn
en movimiento

Catorce animaciones pensadas para exportarse como GIF, desde el hero hasta «About the name». Muninn trabaja en segundo plano; estas piezas enseñan lo que pasa ahí dentro: qué guarda, qué retira, qué bloquea y qué le llega al asistente. Todas se reproducen aquí en vivo. Arrastra la barra de cualquiera para ver un fotograma exacto, o cambia arriba el fondo para verlas como en GitHub claro u oscuro. El texto dentro de las escenas está en inglés, como el README.

Recorrido del README

    Producción

    De la página al GIF

    Cada escena es una función del tiempo: el fotograma del segundo 3,40 siempre es el mismo. Por eso el GIF sale de capturar la página fotograma a fotograma, no de grabar la pantalla, y no hay saltos ni cuadros perdidos. La página expone window.muninnMotion para eso.

    1. Dos archivos por escena. Un GIF no tiene transparencia suave, así que cada escena se exporta sobre el fondo exacto de GitHub: #0d1117 para oscuro y #ffffff para claro, y el README elige con <picture>, igual que hoy con el logo.
    2. El primer fotograma cuenta la historia. Quien tenga desactivada la reproducción automática en GitHub solo ve un cuadro fijo. El script empieza a capturar en el fotograma «póster» de cada escena y da la vuelta, así que el primer cuadro del GIF ya se entiende solo.
    3. 20 fps y 64 colores como punto de partida. Las escenas usan pocos colores planos, que es donde el GIF comprime bien. El peso real hay que medirlo después de exportar; no hay cifra todavía.
    4. Texto alternativo que describa la acción, no «animación». Ejemplo en el fragmento de abajo.
    // export.mjs · node export.mjs hero dark
import { chromium } from "playwright";
import { mkdirSync } from "node:fs";

const [id, v = "dark", fps = 20] = process.argv.slice(2);
mkdirSync("frames", { recursive: true });
const browser = await chromium.launch();
const page = await browser.newPage();
await page.goto("file://" + process.cwd() + "/muninn-motion.html");
await page.evaluate(() => document.fonts.ready);

const s = await page.evaluate(([id, v]) =>
  muninnMotion.prepare(id, v), [id, v]);
await page.setViewportSize({ width: s.w, height: s.h });

const n = Math.round(s.dur * fps);
for (let i = 0; i < n; i++) {
  const t = (s.poster + i / fps) % s.dur;
  await page.evaluate((t) => muninnMotion.frame(t), t);
  await page.locator("#export-stage svg").screenshot({
    path: `frames/${id}-${v}-${String(i).padStart(4, "0")}.png`,
  });
}
await browser.close();
    # frames → GIF con paleta propia
ffmpeg -framerate 20 -i frames/hero-dark-%04d.png \
  -vf "split[a][b];[a]palettegen=max_colors=64:stats_mode=diff[p];\
[b][p]paletteuse=dither=bayer:bayer_scale=4:diff_mode=rectangle" \
  -loop 0 hero-dark.gif

# compresión final
gifsicle -O3 --lossy=40 hero-dark.gif \
  -o assets/motion/hero-dark.gif
